# Projet : Calame

Référence de **substance et de voix** pour rédiger les textes des visuels
(titres, accroches, messages) de Calame. Complète `brand.md`, qui couvre
l'identité visuelle.

> **Marque de démonstration.** Calame n'existe pas. Ce fichier montre ce qu'un
> `project.md` doit contenir pour qu'un visuel puisse être **rédigé** sans
> inventer : un pitch, un public, une voix, et surtout la liste de ce qu'on n'a
> **pas** le droit d'affirmer. Remplace-le par le tien.

---

## 1. En une phrase

Calame est un **atelier d'écriture pour la documentation technique** : il aide
les équipes à écrire ce qu'elles construisent, pendant qu'elles le construisent.

**Titre affiché** : « Écrire pendant qu'on construit ».

## 2. Le produit

Un **outil**, pas une marque personnelle. Il fait trois choses :

- **Rédiger dans le dépôt** : la documentation vit à côté du code, en Markdown,
  et suit les mêmes révisions.
- **Relire à la machine** : Calame signale ce qui a changé dans le code sans
  l'être dans la doc.
- **Publier sans étape** : la version publiée est la branche par défaut, sans
  chaîne de build à entretenir.

Différenciateur revendiqué : la documentation **suit** le code au lieu de courir
derrière lui.

## 3. Public cible

- **Équipes produit et plateforme** qui maintiennent une doc technique vivante.
- **Développeurs solos** qui veulent documenter sans monter un site.

Langue : **français** pour les visuels, ton international pour le produit.

## 4. Proposition de valeur

1. **La doc reste vraie** : ce qui dérive est signalé, pas découvert six mois
   après.
2. **Aucune chaîne à entretenir** : pas de générateur de site à maintenir.
3. **Le dépôt est la source** : une seule version, versionnée avec le code.

## 5. Voix éditoriale

- Ton **sobre, direct, artisanal**. Phrases courtes. Le vocabulaire de l'atelier
  plutôt que celui du logiciel : *tracer*, *relire*, *reprendre*.
- **Vouvoiement** de l'audience. Voix du produit à la troisième personne.
- Format des visuels : **un titre court + une accroche d'une phrase**. Une idée
  par visuel, jamais deux.
- Éviter : superlatifs, buzzwords, ton corporate, promesses de productivité.

## 6. Vocabulaire & claims

- **Nom exact** : **Calame** (majuscule initiale). Le wordmark, lui, s'écrit en
  minuscules : voir `brand.md`.
- **URL** : `_(à définir)_` — marque de démonstration, aucun domaine réel.
- **Accroches validées** : « Écrire pendant qu'on construit », « La doc suit le
  code », « Une seule version, dans le dépôt ».
- **Claims interdits** :
  - **aucun chiffre inventé** : utilisateurs, équipes, temps gagné, taux de
    couverture. Rien de tout ça n'existe ;
  - aucune comparaison nommée à un concurrent ;
  - aucune promesse de résultat non vérifiable.
