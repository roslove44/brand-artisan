# Project: Calame

Reference for **substance and voice** when writing the text on Calame's visuals
(headlines, standfirsts, messages). Complements `brand.md`, which covers the
visual identity.

> **Demo brand.** Calame does not exist. This file shows what a `project.md`
> must contain for a visual to be **written** without inventing anything: a
> pitch, an audience, a voice, and above all the list of what you are **not**
> allowed to claim. Replace it with your own.

---

## 1. In one sentence

Calame is a **writing workshop for technical documentation**: it helps teams
write what they are building, while they are building it.

**Display headline**: "Write while you build".

## 2. The product

A **tool**, not a personal brand. It does three things:

- **Write in the repo**: documentation lives next to the code, in Markdown, and
  goes through the same reviews.
- **Proof by machine**: Calame flags what changed in the code without changing in
  the docs.
- **Publish with no step**: the published version is the default branch, with no
  build chain to maintain.

Claimed differentiator: documentation **follows** the code instead of running
after it.

## 3. Audience

- **Product and platform teams** maintaining living technical documentation.
- **Solo developers** who want to document without standing up a site.

Language: **English** for visuals, international tone for the product.

## 4. Value proposition

1. **The docs stay true**: what drifts gets flagged, not discovered six months
   later.
2. **No chain to maintain**: no site generator to keep alive.
3. **The repo is the source**: one version, versioned with the code.

## 5. Editorial voice

- **Plain, direct, hand-made** tone. Short sentences. The vocabulary of the
  workshop rather than that of software: *draw*, *proof*, *rework*.
- Address the audience directly as **you**. The product's voice stays in the
  third person.
- Format for visuals: **one short headline + a one-sentence standfirst**. One
  idea per visual, never two.
- Avoid: superlatives, buzzwords, corporate tone, productivity promises.

## 6. Vocabulary & claims

- **Exact name**: **Calame** (initial capital). The wordmark itself is set in
  lowercase: see `brand.md`.
- **URL**: `_(to be defined)_`, a demo brand with no real domain.
- **Approved lines**: "Write while you build", "The docs follow the code", "One
  version, in the repo".
- **Forbidden claims**:
  - **no invented figures**: users, teams, time saved, coverage rates. None of
    that exists;
  - no named comparison to a competitor;
  - no promise of an unverifiable outcome.
